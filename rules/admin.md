# Admin Rules

Admin functionality is out of scope for the current landing MVP.

Do not implement:

- `/admin`
- `/admin/login`
- `/api/admin/*`
- `/api/auth/*`
- Better Auth
- admin content editing
- protected admin pages
- admin media management

If admin functionality becomes required later, update `docs/tech_spec/landing_technical_specifications.md` or reactivate the full corporate website specification before implementation.
