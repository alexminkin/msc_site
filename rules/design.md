# Design Rules

The visual identity must communicate innovation, clarity, technology, business competence, improvement, and forward movement.

## Brand Direction

Use the Forward Orbit logo concept:

- clean geometric letter `M`;
- subtle ascending or orbital trajectory;
- optional small endpoint representing a target, data point, or destination;
- abstract technology signal, not literal space imagery.

Required final logo assets:

- horizontal logo;
- compact mark;
- monochrome version;
- light-background version;
- dark-background version;
- favicon based on compact mark;
- primary format: SVG.

## Visual Constraints

Avoid:

- generic robot imagery;
- AI brain icons;
- literal gears;
- overloaded gradients;
- visually dense dashboards on public pages;
- excessive futuristic effects;
- invented proof, unsupported numbers, fake clients, or fake testimonials.

## Layout And Components

- Design with responsive behavior from 320 px upward.
- Keep desktop, tablet, and mobile versions of the same page visually and structurally synchronized through shared components, variables, and styles wherever Figma supports it.
- Reflect copy, navigation, CTA, card, form, and footer changes across all responsive versions in the same design pass.
- Allow breakpoint-specific changes only for responsive layout behavior, not for separate unsynchronized content or visual direction.
- Use predictable navigation and clear conversion paths.
- Use cards only for repeated items or framed tools.
- Keep admin UI utilitarian, dense, and work-focused.
- Keep public UI polished, semantic, and business-oriented.
- Major public pages must include a conversion block before the footer.

## Accessibility

Target WCAG 2.2 AA where reasonably achievable:

- semantic structure;
- visible focus states;
- keyboard navigation;
- sufficient color contrast;
- labeled form inputs;
- meaningful alt text;
- no hover-only interactions;
- reduced-motion support where motion exists.
